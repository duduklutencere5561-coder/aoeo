2. Öncelik Diyagramı (AON Notation)

M1 ─┬─→ M2 ──→ M4 ──→ M5 ──→ M6 ──→ M7 ──┐ │ │ └─→ M3 ──→ K1 ───────────────────────→ │ ↓ M8 ──→ K2 ──→ K3 ──→ M9

Diyagramda iki paralel kol var:

  • Üst kol: M1 → M2 → M4 → M5 → M6 → M7 → (M8)
  • Alt kol: M1 → M3 → K1 → (M8)
  • İki kol M8'de birleşir (kapak-gövde birleştirme)
  • Sonra tek sıralı: M8 → K2 → K3 → M9

3. CPM (Critical Path Method) Hesabı

ES = max(EFöncekiler)   |   EF = ES + t
LF = min(LSsonrakiler)   |   LS = LF − t
Slack = LS − ES = LF − EF

4. Slack (Bolluk) Analizi

İki paralel kol arasındaki süre farkı:

  • Üst kol süresi: M2+M4+M5+M6+M7 = 6+10+8+10+5 = 39 sn
  • Alt kol süresi: M3+K1 = 8+3 = 11 sn
  • Fark: Alt kol 28 sn daha kısa → bu kol 28 sn slack taşır
  • Tüm kritik olmayan görevlerin slack'i 20 sn (üst kolun M2'den önceki kısmı)

5. Kritik Yol

M2 → M4 → M5 → M6 → M7 → M8 → K2 → K3 → M9

Süresi: 73 saniye

Yorum:

  • Kritik yol uzunluğu 73 sn, takt süremiz 63 sn. Bu nedenle tek operatör tek istasyonda yapamaz — hat dengeleme gerekli.
  • Teorik minimum istasyon sayısı: ⌈92/63⌉ = 2 istasyon
  • Ancak kritik yol 73 > takt 63 olduğu için pratikte 3 istasyon gerekir.
  • Bu Adım 8 hat dengelemenin temel girdisidir.
