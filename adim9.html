ADIM 09

Hücresel İmalat ve Makine Gruplama.

Karmaşık parça rotalarını optimize etmek için ROC (Rank Order Clustering) algoritması kullanılarak üretim tesisinin 3 bağımsız imalat hücresine bölünmesi.

Sayfada
Amacımız ROC Algoritması Optimize Matris Oluşan Hücreler Performans (Efficacy)

1. Neden Hücresel İmalat?

Geleneksel atölye (Process Layout) tipinde parçalar, makineler arası sürekli gidip gelir. Bu durum "Spagetti Diyagramı" dediğimiz karmaşık malzeme akışına, yüksek taşıma maliyetlerine ve uzun WIP (süreç içi stok) bekleme sürelerine neden olur.

Amacımız, benzer üretim rotalarına sahip parçaları (Parts) ve bu parçaları işleyen makineleri (Machines) aynı **Üretim Hücreleri (Cells)** içine alarak tesis içi malzeme akışını minimize etmektir.

2. ROC (Rank Order Clustering) Algoritması

J.R. King (1980) tarafından geliştirilen bu algoritmada, Parça-Makine matrisindeki satır ve sütunlara ikili sistem (binary) ağırlıkları atanır. İteratif olarak ağırlıklar büyükten küçüğe sıralanarak matrisin "Blok Köşegen (Block-Diagonal)" hale gelmesi sağlanır.

Proje kapsamında 96 makine ve 21 bileşenden oluşan devasa matrisin elle hesaplanması hata payını artıracağı için süreç, teslim edilen Python (NumPy/Pandas) kodu ile çözülmüştür.

3. Optimize Edilmiş Parça-Makine Matrisi

Aşağıda, algoritma çalıştırıldıktan sonra bloklanan nihai matrisin sadeleştirilmiş bir özeti yer almaktadır. Renkli kutular oluşan üretim hücrelerini temsil eder.

Makine \ Parça P1 (Gövde) P2 (Kapak) P4 (Taban) P7 (Valf) P8 (Boru) P12 (Kulp)
M1 (Hidrolik Pres) 1 1 0 0 0 0
M2 (Eksantrik Pres) 1 1 1* 0 0 0
M5 (Kıvırma Mak.) 1 1 0 0 0 0
M7 (CNC Torna) 0 0 1 1 1 0
M9 (Lazer Kaynak) 0 1* 1 1 1 0
M14 (Bakalit Enj.) 0 0 0 0 0 1
M15 (Polisaj Robotu) 1* 1* 0 0 0 1

* İstisnai Hareketler (Exceptional Elements - Yıldızlı alanlar): İlgili hücre dışına çıkan mecburi malzeme hareketleridir (Örn: Gövdenin pres hücresinden çıkıp polisaj hücresine gitmesi).

4. Oluşturulan Üretim Hücreleri

Hücre 1: Ağır Pres Hattı
A
Gövde ve kapak derin çekme işlemleri. 14 Makine, 8 Operatör.
Hücre 2: Talaşlı İmalat
B
Taban, valf, boru (CNC, Kaynak). 12 Makine, 5 Operatör.
Hücre 3: Yüzey & Montaj
C
Bakalit üretim, polisaj ve son montaj. 26 Makine, 12 Operatör.

5. Hücre Performansı: Grouping Efficacy (GE)

Oluşturduğumuz makine gruplarının matematiksel olarak ne kadar başarılı olduğunu ölçmek için Kumar & Chandrasekharan'ın (1990) Grouping Efficacy ($\tau$) formülü kullanılmıştır.

$\tau = \frac{e - e_v}{e + e_o}$
  • e: Matristeki toplam işlem (1) sayısı (Toplam 84 operasyon)
  • $e_v$: İstisnai eleman sayısı (Hücre dışı taşıma, 7 adet)
  • $e_o$: Hücre içindeki boş (0) eleman sayısı (11 adet)

Algoritma sonucunda tesisin Gruplama Etkinliği (Grouping Efficacy) %81.05 olarak hesaplanmıştır. Endüstriyel bir tesis tasarımı için %75'in üzerindeki değerler mükemmel kabul edilir. Bu durum hücreler arası taşımaların minimuma indirildiğini kanıtlar.
