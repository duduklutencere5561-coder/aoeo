A. King (1980) Rank Order Clustering (ROC) — Adım 9

Parça-makine ilişkisini köşegen blok haline getirmek için kullanılan ikili taban (binary) ağırlıklandırma döngüsü[cite: 1008]:

def rank_order_clustering(Matrix):
    while True:
        # 1. Satır skorlarını hesapla ve sırala (Sağ bit en yüksek ağırlık)
        row_scores = [sum(M[r,c]*(2**(n-1-c)) for c) for r]
        Matrix = Matrix[sorted_indices(row_scores, reverse=True)]
        
        # 2. Sütun skorlarını hesapla ve sırala (Alt bit en yüksek ağırlık)
        col_scores = [sum(M[r,c]*(2**(m-1-r)) for r) for c]
        Matrix = Matrix[:, sorted_indices(col_scores, reverse=True)]
        
        if no_change_in_matrix: break # Kararlı duruma ulaşınca çık
    return Matrix

B. CRAFT İteratif İyileştirme Döngüsü — Adım 14

Bölümler arası Manhattan mesafelerini ve akış hacimlerini çarparak en büyük tasarrufu sağlayan ikili yer değişimini (swap) bulan heuristik yapı[cite: 729, 774, 1021]:

while True:
    best_swap = None
    current_cost = calculate_total_cost(layout, flow, distance)
    
    for i, j in all_valid_department_pairs:
        simulated_layout = swap_departments(layout, i, j)
        new_cost = calculate_total_cost(simulated_layout)
        
        if new_cost < current_cost and check_safety_constraints(simulated_layout):
            best_swap = (i, j)
            current_cost = new_cost
            
    if best_swap is None: break # Lokal optimuma ulaşıldı, sonlandır
    layout = apply_swap(layout, best_swap)
